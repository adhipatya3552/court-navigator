# PRODUCT_SCOPE.md

## Supported in V1 (fully functional)

- **Jurisdiction:** Madhya Pradesh
- **Court:** District Court / Trial Court
- **Matter:** Criminal — Bail navigation
- **Journey:** 7 stages (Prepare → Filing → Scrutiny → Listing → Hearing → Order → Next), 10-item checklist, 14-term EN/HI glossary, document decoder (order/notice/summons text), What-Happens-Next panel, structured assistant, source registry.

## Why this narrow slice

A nationwide all-court platform would create an unmanageable accuracy surface. One journey done exceptionally well proves the engine: jurisdiction-aware retrieval + deterministic mapping + plain-language explanation + visible provenance. The same schema (`jurisdiction → court → matter → stage → step → checklist → glossary → source`) extends to new journeys without redesign.

## Explicitly NOT in V1 (and not faked)

Generic AI lawyer · outcome prediction · litigation strategy · legal research engine · nationwide procedure DB · case management/CRM · drafting autonomy · live e-filing integration · auth/payments · community platform · PDF/image OCR. Unsupported courts/procedures render an honest “Coming Soon — not answered as verified” state.

## Expansion path

Civil · family · consumer · criminal-beyond-bail · High Court · Supreme Court · more states · more languages · reminders · cause-list sync · legal-aid routing · lawyer handoff. Shown on the Scope section as a roadmap, not as functionality.
